# AI Use Declaration

Claude Code (Anthropic) was used as a programming assistant for code scaffolding, debugging and test generation, and for language
editing and checking of bibliographic details. Google Gemini is used only at run time inside the application's assistant, where it may
phrase answers solely from tool outputs (database queries, model inference, simulation and optimisation).

All research design choices, experiments, results and interpretations were reviewed and verified by the authors — Shraddha Shete,
Shirsodeep Biswas and Jayant Kumawat — who take full responsibility for the content of the report and the accompanying code.
