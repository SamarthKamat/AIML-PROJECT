## Security
* Passwords: Werkzeug salted hashes. Sessions: HS256 JWT, 12 h expiry, secret from `JWT_SECRET`.
* All `/api/*` routes except `auth/*`, `health` and `docs` require a bearer token.
* SQL via SQLAlchemy Core or bound parameters. The few table names interpolated into SQL are whitelisted against `DATA_TABLES`.
* Upload limits: 20 MB; only `.csv`, `.xlsx` and `.xls`. Uploads are validated and logged, never merged into master tables.
* The API key lives only in an environment variable; `.env` is git-ignored.
